## 🔍 최종 검토 및 데이터 교환 검증 항목

### 1. 학급 & 프로필 수정 및 권한 검증 (Firestore Security Rules)
- **교사 권한 수정**: 교사의 학급 이름 변경 및 학생 프로필 수정 시 `Missing or insufficient permissions` 오류 해결 완료.
- **학생 개인 정보 보호**: 학생이 자신의 비밀번호 및 프로필 정보를 안전하게 변경할 수 있도록 개별 문서 업데이트 권한 동기화 완료.

### 2. 교사 관리자 대시보드 - 미션 승인 및 관리 시스템
- **실시간 승인 대기 푸시 알림**: 대기 중인 학생 미션 제출 건수 표시 및 미션 관리 메뉴 뱃지 카운터(`🔔 N`) 연동.
- **상태별 접기/펼치기 Accordion**: '대기 중', '승인됨', '반려됨' 그룹별 제출 내역 보기 및 대기 항목의 일괄 처리('전체 승인') 기능 제공.
- **자동 승인 내역 명시**: 시스템 자동 승인 항목에 `시스템 자동 처리` 태그 및 펼치기 기능 제공.
- **미션 유형 필터링**: '친절', '배려', '관찰' 등 카테고리별 제출 내역 탭 필터링 추가.
- **최근 제출 미션 강조**: 새로 들어온 미션 카드에 호박색 발광 테두리 및 `✨ 최근 제출됨` 태그 적용.

### 3. 실시간 익명 라운지 및 동시 접속자 수 추적
- **접속 인원 실시간 확인**: 대기실 없이 현재 라운지 화면에 동시 접속 중인 학생 및 교사 수(`👀 현재 라운지 접속 X명`)를 실시간 카운팅하여 상단 뱃지로 공유.
- **안전 규칙 및 신고**: 라운지 메시지 작성 시 비속어 필터링 및 선생님 직속 신고 기능 유지.

### 4. 학생 미션 승인 & 뱃지 달성 실시간 축하 팝업 모달
- **선생님 미션 승인 점수 부여 팝업**: 교사가 미션을 승인하면 학생 화면에 실시간으로 `👨‍🏫 선생님이 미션을 승인하셨어요!` 팝업 모달과 보상 점수(`+N점 ★`)가 노출됩니다.
- **뱃지 달성 완료 팝업**: 뱃지 진행률 100% 달성 시 `🏆 뱃지 획득 완료!` 모달이 노출됩니다.
- **Web Audio Chime 효과음**: 외부 오디오 파일 링크 단절 위험이 없는 Web Audio API 기반 Chime 사운드가 브라우저 호환성 높게 동작합니다.
- **중복 팝업 방지**: `localStorage`를 활용하여 실시간 소켓 업데이트 중복으로 인한 연속 팝업 노출 방지.
